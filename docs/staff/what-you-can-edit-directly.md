# What you can edit directly

Use this guide when your account (or AI session) has permission to **change the site now** — edit live or draft pages, create pages, publish drafts, manage media, redirects, products, content lists, and more. **No Approver inbox is required** for those actions.

If instead you work through the **swarm proposal path** (specialists draft; someone else greenlights/approves) or you own **Diagnostics / Proposals**, see [What the agent swarm can do](what-the-agent-swarm-can-do.md).

**CMS without chat:** Many of the same jobs can be done in the staff CMS UI (page editor, media gallery, redirects, and so on). This guide describes the freedom in marketing terms; chat is optional.

Words like draft, publish, language version, and shared template mean the same as in the [swarm guide glossary](what-the-agent-swarm-can-do.md#quick-glossary).

---

## Hard truths (read once)

- **Live can change immediately.** Prefer a **private draft** when you are unsure, then publish the draft `(Promote)` when ready.
- **Permissions still matter.** Security → Users controls whether AI chat can write and which areas you can touch. Without write, you are propose-only or read-only — use the [swarm guide](what-the-agent-swarm-can-do.md).
- **Production may ask for a connected session.** If a write is refused, ask ops; do not assume the site is broken.
- **Other languages do not update automatically.** Editing English does not rewrite Spanish (or the reverse).
- **After a big publish,** re-checking page quality is good practice — see Diagnostics in the [swarm guide](what-the-agent-swarm-can-do.md#8-site-quality-diagnostics). This guide does not cover that inbox.
- **Still out of scope:** store “for sale” flags, inventing traffic numbers, and controlling ad platforms.

---

## Permission areas (plain English)

Your role may include some of these. If an action fails, you likely lack that area.

| Area | Typical freedom |
|---|---|
| **View content** | Read pages, products, components, media list |
| **Edit text** | Body copy, translations onto drafts, single-field text |
| **Edit structure** | Sections, shared templates, product journey structure |
| **SEO** | Titles, descriptions, search fields, keyword research |
| **Create pages** | New pages of types you’re allowed to create (not every product type) |
| **Delete pages** | Remove static entries (preview first, then confirm) |
| **Create / delete drafts** | Private test versions of a page |
| **Publish drafts** | Publish draft → live, or unpublish live → draft |
| **Media** | Upload/import gallery assets; refresh social previews |
| **Redirects** | Test where a path goes; add/move redirects |
| **Products** | View offers; update product details (with confirm) — not sell flags |
| **Content lists** | FAQ and similar banks: add/edit/delete rows |
| **Manage content lists** | Create/configure banks; refresh search index |
| **Content types** | Adjust type strategy/fields/shared-template flags (high care) |
| **SEO settings** | Rare bulk rich-result seeding for a type |
| **Metrics** | Organic traffic and named analytics reports |

## How each use case is written

1. **Situation** — everyday marketing work  
2. **You (or your AI) can…** — direct action that changes draft or live  
3. **Watch out for…** — what spreads, what does not, when to use a draft  
4. **Usually needs…** — permission area from the table above  

---

## 1. Content and storytelling

### Rewrite page copy (live or draft)

**Situation:** Headlines or body text need a refresh; layout stays the same.

**You (or your AI) can…** Edit text on the live page or on a private draft right away.

**Watch out for…** Live edits are public immediately. Prefer a draft for big rewrites. Other language versions stay unchanged.

**Usually needs…** Edit text.

---

### Add, remove, or reorder sections

**Situation:** Add a testimonial, drop a weak block, or move the CTA higher.

**You (or your AI) can…** Change section structure on live or draft.

**Watch out for…** Shared templates can affect many pages — confirm when asked. Prefer a draft for large restructures.

**Usually needs…** Edit structure.

---

### Create a new page

**Situation:** Marketing needs a new URL for a campaign or topic.

**You (or your AI) can…** Create a new page (draft or following your site’s create playbook) and fill content without filing an idea proposal first.

**Watch out for…** Not every content type is created this way (some are database-backed or restricted). Check for duplicates. Swarm roles may still be told to propose instead — this guide assumes you have create permission.

**Usually needs…** Create pages (+ edit text / structure to fill it).

---

### Private draft, then publish

**Situation:** You want to test before visitors see the change.

**You (or your AI) can…** Create a private draft, edit it, then publish it over live `(Promote)`, or publish an unpublished draft to live.

**Watch out for…** Live search title/description may stay until you change live SEO on purpose after publish. Confirm if asked to end an experiment.

**Usually needs…** Create drafts + Publish drafts (+ Edit text / structure).

---

### Unpublish a live language version to draft

**Situation:** Take one language offline without deleting the page.

**You (or your AI) can…** Convert that live language version to a draft.

**Watch out for…** Visitors on that language lose the page until you publish again. Other languages are untouched.

**Usually needs…** Publish drafts.

---

### Translate onto a draft

**Situation:** English exists; Spanish (or another language) should too.

**You (or your AI) can…** Write the translation onto a **private draft** for that language (not the live page yet), then publish when ready.

**Watch out for…** Direct translate does not write the live language file. Publish is a separate step. No silent fan-out to every language.

**Usually needs…** Edit text (+ Publish drafts to go live).

---

### Leave or rejoin a shared page template

**Situation:** A page needs a one-off layout — or should return to the shared template.

**You (or your AI) can…** Detach or reattach with confirmation.

**Watch out for…** Can affect many pages. Confirm carefully; mistakes are expensive.

**Usually needs…** Edit structure.

---

### Delete pages

**Situation:** A static page should go away.

**You (or your AI) can…** Preview the delete, then confirm. Related links may need reassignment first.

**Watch out for…** Irreversible for visitors. Prefer redirects if the URL had traffic.

**Usually needs…** Delete pages.

---

## 2. SEO and discoverability

### Edit title and description on the live page

**Situation:** The search snippet needs a better title or description now.

**You (or your AI) can…** Change SEO fields on the live page (or a draft) immediately.

**Watch out for…** Check recent activity so you do not overwrite a paid or SEO test mid-flight. Measured clicks lag behind the edit.

**Usually needs…** SEO (or edit text, depending on the field).

---

### Fix rich-result info for Google

**Situation:** A page is missing the extra info Google uses for rich results.

**You (or your AI) can…** Add or fix those sections on specific pages. Rare ops may seed a whole type (high care).

**Watch out for…** Prefer targeted page fixes over bulk seeding on selling pages.

**Usually needs…** SEO; bulk type seeding needs SEO settings.

---

### Topic groups and internal links

**Situation:** Strengthen a main page and its related articles.

**You (or your AI) can…** Read topic membership, then edit copy and links directly on the pages.

**Watch out for…** Do not invent thin new URLs without demand; creating a page still needs create permission and judgment.

**Usually needs…** View content + Edit text / SEO.

---

### Keyword research vs real traffic

**Situation:** You need ideas and honest click data.

**You (or your AI) can…** Run keyword/competitor research (confirm budget when asked) and read measured organic traffic, then edit pages directly from what you learned.

**Watch out for…** Research does not invent Search Console numbers. Research does not auto-write SEO fields — you still edit the page.

**Usually needs…** SEO and/or Metrics.

---

### Update the same attributes on many URLs

**Situation:** Many pages need the same SEO or journey attribute change.

**You (or your AI) can…** Apply a bulk attribute update across a list of pages (within limits).

**Watch out for…** Can change many pages at once. Preview intent carefully; this is not a full body rewrite.

**Usually needs…** SEO and/or Edit structure (depending on the attribute).

---

### Language URL conflicts

**Situation:** Two language versions collide on a URL shape.

**You (or your AI) can…** Fix slugs/meta and add redirects so old paths keep working.

**Watch out for…** Coordinate with campaigns and bookmarks before changing live URLs.

**Usually needs…** SEO + Redirects (+ Edit structure if layout is involved).

---

## 3. GEO and brand consistency

### Improve pages that feed brand / AI-answer views

**Situation:** Diagnostics → GEO (or brand views) look weak because underlying pages are inconsistent.

**You (or your AI) can…** Fix facts, naming, rich-result info, and educational copy on the live pages directly.

**Watch out for…** Interpreting GEO boards is still your judgment. For inbox triage of health issues, use the [swarm guide](what-the-agent-swarm-can-do.md#8-site-quality-diagnostics).

**Usually needs…** Edit text + SEO.

---

### Align product and audience naming

**Situation:** “Bootcamp” vs “course” vs wrong product name across the journey.

**You (or your AI) can…** Edit page copy and journey tags directly.

**Watch out for…** Official vocabulary is a business decision. Mis-tags poison funnel reports.

**Usually needs…** Edit text and/or Edit structure / SEO for tags.

---

## 4. Ecommerce and offers

### Refresh offer copy and product details

**Situation:** A product’s public story is stale.

**You (or your AI) can…** Update related pages and product details (with confirmation when required).

**Watch out for…** **For sale / actively selling** flags stay human (Store). Agents cannot flip them even with broad write access.

**Usually needs…** Edit text / Edit structure + Products view/update.

---

### Map and fix a product journey

**Situation:** Awareness → consideration → conversion pages are missing or mis-tagged.

**You (or your AI) can…** Read the journey and analytics, then set journey tags and fix page copy directly.

**Watch out for…** Analytics never auto-create pages. Creating missing stages needs create permission.

**Usually needs…** View content + Edit structure / SEO + Metrics (for reports).

---

### Selling-page numbers and proof

**Situation:** Outcomes or pricing cues on a selling page.

**You (or your AI) can…** Edit those fields live or on a draft.

**Watch out for…** Invented numbers are a brand risk. Prefer a draft + human review even when you *can* edit live. For a formal review inbox, use [proposals in the swarm guide](what-the-agent-swarm-can-do.md#9-proposals-and-review).

**Usually needs…** Edit text.

---

## 5. Marketing and conversion

### Fix CTA and lead-form tracking names

**Situation:** Tracking names/tags on a page do not match GTM/ads expectations.

**You (or your AI) can…** Correct them on the page immediately.

**Watch out for…** Wrong names break reporting even if the form works. Marketing ops owns the naming convention.

**Usually needs…** Edit structure or Edit text (where the CTA lives).

---

### Set journey tags on pages

**Situation:** Pages need product, audience, and stage tags for funnel reporting.

**You (or your AI) can…** Write those tags directly (often shared across language versions for that page’s common settings).

**Watch out for…** Mis-tags poison dashboards. Confirm the taxonomy with your funnel owner.

**Usually needs…** Edit structure and/or SEO.

---

## 6. Paid / PPC and campaigns

### Build a campaign landing now

**Situation:** Paid needs a URL for next week’s ad set.

**You (or your AI) can…** Create and fill the landing (draft first recommended), then publish when spend starts.

**Watch out for…** Ad platforms stay outside this CMS. Pause/create campaigns yourself in Google/Meta.

**Usually needs…** Create pages + Edit text/structure + Publish drafts + SEO.

---

### Redirect after a campaign ends

**Situation:** Old ad URLs still get traffic.

**You (or your AI) can…** Test the path and add a redirect to the best live page.

**Watch out for…** For 404 log triage, ignore rules, and broken-URL *ideas*, see the [swarm guide](what-the-agent-swarm-can-do.md#8-site-quality-diagnostics). This guide covers the redirect itself.

**Usually needs…** Redirects (read + edit).

---

## 7. Media and creative

### Find or import an image

**Situation:** A section needs a gallery image or a public URL import.

**You (or your AI) can…** Search the gallery, import from a public URL when allowed, and attach it on the page.

**Watch out for…** Rights and brand fit. Reject off-brand imports.

**Usually needs…** Media (upload) and/or View content; Edit text/structure/media to attach on the page.

---

### Refresh the social share preview

**Situation:** LinkedIn/Slack still shows an old image.

**You (or your AI) can…** Queue regeneration of the page’s social share preview.

**Watch out for…** Social networks may cache their own copy.

**Usually needs…** Media.

---

## 8. Redirects and URL hygiene

### Test where a path goes

**Situation:** Before changing ads or sitemaps, confirm the winner and conflicts.

**You (or your AI) can…** Test a URL and see which rule wins.

**Watch out for…** Fix conflicts before adding another rule that fights the first.

**Usually needs…** Redirects (read).

---

### Add or move a redirect

**Situation:** Legacy or campaign URL must land on the new page.

**You (or your AI) can…** Add, delete, or move a CMS redirect after testing.

**Watch out for…** Prefer exact old paths so visitors are not bounced twice. Ignoring a row in Runtime issues is not a redirect.

**Usually needs…** Redirects (edit).

---

## 9. Content lists and banks

### Maintain FAQs and similar lists

**Situation:** Reusable rows (FAQ answers, and so on) live in content banks.

**You (or your AI) can…** Add, edit, or delete rows (delete needs confirm). Refresh search over that bank when needed.

**Watch out for…** Shipping/sync habits for banks may differ from a normal page publish. Know your site’s process.

**Usually needs…** Content lists; Manage content lists for reindex/config.

---

### Create or reconfigure a content bank

**Situation:** Ops needs a new bank or a deep config change.

**You (or your AI) can…** Create or update bank configuration (confirm on update).

**Watch out for…** High care — wrong config breaks editors and search. Prefer a dry run with ops.

**Usually needs…** Manage content lists.

---

## 10. Content types and templates

### Adjust a content type’s strategy or fields

**Situation:** Staff need to change how a type is described, add/update/remove a mapping field, or change shared-template flags.

**You (or your AI) can…** Patch one mode at a time with preview, then confirm to execute.

**Watch out for…** Does **not** rewrite existing page content by itself. Required fields and strategy rules can block the change. Treat as ops-level work.

**Usually needs…** Content types.

---

### Rare: seed rich-result sections across a type

**Situation:** Many pages of a type lack leading rich-result sections.

**You (or your AI) can…** Run a bulk seed when permitted.

**Watch out for…** Prefer targeted page fixes. Bulk seed is ops/SEO-settings territory.

**Usually needs…** SEO settings.

---

## 11. Components and previews

### Browse section types and field definitions

**Situation:** You need to know which section to add and what fields it expects.

**You (or your AI) can…** List components, read when-to-use guidance, field definitions, and where a component is already used.

**Watch out for…** Reading does not change the site. Adding the section still needs edit structure.

**Usually needs…** View content.

---

### Disposable section preview (not a publish)

**Situation:** You want a quick visual of one section before committing it to a real page.

**You (or your AI) can…** Create a temporary single-section preview URL.

**Watch out for…** Not a publish; wiped on redeploy; anyone with the URL hash can open it. Do not treat it as the live page.

**Usually needs…** View content.

---

## 12. Analytics-informed edits

### Prioritize from organic traffic, then edit

**Situation:** Limited time; you want real impressions/clicks first.

**You (or your AI) can…** Read organic traffic for paths or topic groups, then edit those pages directly.

**Watch out for…** Do not invent traffic numbers. Business priority can still override pure traffic rank.

**Usually needs…** Metrics (+ Edit text / SEO to act).

---

### Use named analytics reports, then edit

**Situation:** A funnel or named report shows underperforming steps.

**You (or your AI) can…** Pull the report and fix copy, tags, or structure on the pages involved.

**Watch out for…** Reports never auto-edit pages.

**Usually needs…** Metrics (+ the matching edit permission).

---

## 13. When to still use proposals or Diagnostics

Direct edit is powerful. Prefer the [swarm / proposals path](what-the-agent-swarm-can-do.md) when:

- Your account is **propose-only** or write is off.
- Policy says **someone else must approve** (selling pages, legal, brand-sensitive claims).
- You want a durable review trail (idea → greenlight → edits) instead of a silent live write.
- You are triaging **Global Health**, **Runtime issues (404s)**, or the **Proposals** inbox — those workflows live in the other guide.

Direct edit is usually enough when:

- You own the page and have write permission.
- The change is routine (typo, tracking name, redirect, draft publish you already reviewed).
- You are comfortable owning an immediate live change.

---

## What direct edit still will not do

- Change bids, budgets, or creatives in Google Ads, Meta, or other ad platforms.
- Flip store **for sale** / **actively selling** flags.
- Update every language version when you edit one.
- Invent Search Console clicks, keyword volumes, or 404 hit counts.
- Replace Proposals or Diagnostics as the shared review/health boards (use the [other guide](what-the-agent-swarm-can-do.md)).
- Bypass Security permissions you were not granted.
- Replace your brand, legal, and factual judgment on selling pages.

---

## One-sentence mental model

**With direct edit permission, you (or your AI) can change drafts and live pages now; with the swarm path, specialists propose and a different person approves — pick the path that matches your permissions and risk.**
